# Poultry Inventory Management System

A simple, responsive web application designed to manage poultry inventory and process customer orders efficiently. The system tracks available chickens, legs, wings, and flesh portions while updating stock after each successful order.

## Features

- **Inventory Initialization** – Set the initial number of chickens in stock.
- **Stock Management** – Track available chickens, legs, wings, flesh portions, and total weight.
- **Order Processing** – Process orders for chicken legs, wings, and flesh portions.
- **Input Validation** – Validate quantities and display error messages for invalid inputs.
- **Real-Time Updates** – Automatically update inventory after successful orders.
- **Stock Status Indicators** – Display visual indicators for inventory levels.
- **Responsive Design** – Supports desktop and mobile screens.
- **Reset Form** – Clear order inputs and results.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

### Prerequisites

A modern web browser such as Google Chrome, Microsoft Edge, or Firefox.

## 💻 How to Use

1. Enter the initial number of chickens.
2. Click **Initialize Inventory** to set up the stock.
3. Enter the required quantities of chicken legs, wings, and flesh portions.
4. Click **Place Order** to process the order.
5. View the order summary and updated inventory.
6. Use **Reset Form** to clear the order fields and results.
